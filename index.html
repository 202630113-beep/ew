GitHub Pages 무료 배포 방법

💡 `index.html` 파일 단 하나로 나만의 AI 시험 분석 웹사이트를 배포할 수 있습니다.
  1. GitHub 로그인 및 Repository 생성: github.com 접속 후 New Repository 생성
  2. index.html 파일 업로드: uploading an existing file 선택 ➔ 이 파일(index.html) 업로드 ➔ Commit changes 클릭
  3. GitHub Pages 설정: 저장소 메뉴 Settings ➔ Pages 선택
  4. Branch 설정: Branch를 main으로 바꾸고 Save 클릭
약 1~2분 후 생성된 웹사이트 링크로 자유롭게 접속하실 수 있습니다.
